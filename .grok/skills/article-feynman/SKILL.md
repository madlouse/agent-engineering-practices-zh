# 三分钟费曼短片

讲解放在标题、摘要、语言切换之后，目录和正文之前。它解释精华，不代替原文。

画面是竖屏短片，不是一段静态文案。用 Remotion（`remotion` 与 `@remotion/player` 同一精确版本）嵌在页面里。每一镜都用图或表把机制演出来：因果要看得见，比较要能对上，专名保持原文。不要把旁白整段贴上屏幕。

## 五镜，顺序固定

1. 用大白话。一个流程，不出现只有读过全文才懂的缩写。
2. 容易听错。错的那句划掉，对的那句留下。有原文里的数量对比时，做成条，并写明不是本站复测。
3. 一个比喻。最多三个物件。标明「讲解图，不是原图」。
4. 不能译的原件。只列原文的专名、图号或原句，指向正文里的原件，不另画一张冒充原图。
5. 一句话。一句判断，字要大到放大前也能读。

旁白文件是 `public/explainers/{slug}.zh.mp3` 和 `{slug}.en.mp3`，旁边的 json 给出时长和五镜起点。中文声线是 `zh-CN-XiaoxiaoNeural`（晓晓），英文声线是 `en-US-AndrewNeural`。播放器按这份时长切镜。换语言就换文件，不共用一条声线。

## 人体工学

- 一镜只讲一件事。视线从上到下：镜号、图、一句判断。
- 竖屏 1080×1920。默认按视口高度适应，不把整页撑到要翻很久才看见播放条。
- 播放条一直在。空格播放，点击画面播放，可全屏。
- 缩放三档：适应、放大、再放大。放大后在短片区域内滚动，字变大，方便看清表。
- `prefers-reduced-motion` 时直接给出该镜的定格，不播过程。

## 不要

- 不要用十几秒的生成影像冒充讲解。
- 不要新的色相，不要表情符号。
- 旁白和图上的数字必须是原文已有的，实验数字要说「不是本站复测」。

## 做完

一个没读过原文的人，能否只靠这五镜说出文章在争什么，以及哪一件是不能译的。不能，就改短片，不改正文。

改播放器之前，Call the Skill tool with `principle-experience-first`，再打开 `design-ui`。
屏幕上的短句写完后，Call the Skill tool with `unslop`。旁白里的原文专名不改写。
