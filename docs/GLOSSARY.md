# 术语表

中英文案、代码命名、文档都按这张表用词。PRD 第 12 节是同一张表的在线版本，两边一起改。

**原则：用户已经熟悉的词。** 站名、栏目、按钮和所有专有名词都用常见说法，中英文都能一眼看懂，不另起需要解释的名字。品牌和产品名（Velicoach、Veli）除外，第一次出现时带一句说明。

| 中文 | English | 含义 |
|---|---|---|
| Velicoach | Velicoach | 主站品牌：AGI 路上的陪练 |
| 身体 | Body | 第一站：力量训练与长期健康，产品是 Veli。路径 `/body` |
| AI | AI | 第二站：AI 与 agent 的大事记、学习路径和工程实践。路径 `/ai` |
| 项目 | Projects | 第三站：和 agent 一起做出能用的东西，附开发日志。路径 `/projects` |
| 威利 | Veli | AI 力量训练教练，品牌与教练同名 |
| 薄肌计划 | 以 Veli PRD 为准 | Veli 的训练计划名，只在中文里用 |
| 订阅 | Newsletter（按钮 Subscribe） | 每周日一封邮件：一读、一练、一个可以动手做的项目 |
| 开发日志 | Devlog | 公开记录我们怎样和 agent 一起做产品 |
| 大事记 | Timeline | AI 站的内容线：AI 发展的重要节点 |
| 学习路径 | Learning path | AI 站的内容线：从 CS 课程到 agent，再到模型 |
| 工程实践 | Engineering | AI 站的内容线：从 prompt 到 context、loop、graph 的工程演进 |
| 今天的训练 | Today's workout | 身体站给出的当天训练入口 |
| 3 分钟视频 | 3-minute video | 文章开头的讲解视频，中文旁白晓晓，英文旁白 Andrew |
| agent | agent | 能自己调用工具、把一件事做完的 AI |
| 外观 | Appearance | 主题设置：自动（跟随系统）、浅色、深色 |

口号「先站稳，再看清，然后动手」（Get strong. See clearly. Build.）只用在首页，不当站名。

设计和工程内部用语（不出现在界面上）：叶与网（首页主动效）、书脊（进入一站后另一站收成的窄条）、步数预算、原地展开。

## 不再用的说法

| 不再用 | 改用 | 原因 |
|---|---|---|
| 站稳、看清、动手（作站名）；Stand strong、See clearly、Mind、Build（作站名） | 身体、AI、项目；Body、AI、Projects | 站名要用户一眼看懂；Mind 在英文里容易被理解成心理健康（11-04） |
| 同席、With | 不另起刊名，就是 AI 站 | 听起来奇怪；With 太泛，搜不到（同席原句第 20 条，11-04） |
| 每周邮件、周信、Weekly email | 订阅、Newsletter | 用常见说法（11-04）；「周信」是自造词 |
| build 日志、Build log | 开发日志、Devlog | 用常见说法 |
| 里程碑、专业进阶（作栏目名） | 大事记、学习路径 | 用常见说法 |
| 今日一练 | 今天的训练 | 用常见说法 |
| 讲解短片 | 3 分钟视频 | 用常见说法 |
| `/mind`、`/build`、`with.velicoach.com` | `/ai`、`/projects` | 路径和站名一致；旧地址永久跳转 |
| 搏击、搏击教练 | 力量训练、薄肌、Veli | 产品做的是健身薄肌，不是对抗性的搏击 |
| worrycoach、Value Coach | Velicoach | 语音转写和早期设想 |
| 落地实践 | 不再使用 | 原同席博客最早的名字 |
| xAI 的 prompt | （删除） | 语音转写错误 |
| 了解更多 | 写点了之后得到什么 | 两步原则：按钮直达结果 |
