# 术语表

中英文案、代码命名、文档都按这张表用词。PRD 第 12 节是同一张表的在线版本，两边一起改。

| 中文 | English | 含义 |
|---|---|---|
| Velicoach | Velicoach | 主站品牌：AGI 路上的陪练 |
| 站稳 | Stand strong（站点名 Body） | 身体一站：力量训练与长期健康 |
| 看清 | See clearly（站点名 Mind） | 心智一站：AI 与 agent |
| 动手 | Build | 和 agent 一起做出能用的东西 |
| 威利 | Veli | 薄肌教练兼管家，品牌与 AI 教练同名 |
| 薄肌计划 | 以 Veli PRD 为准 | Veli 的训练计划名，只在中文里用 |
| 同席 | With | 心智站的刊名 |
| 每周邮件 | Weekly email | 每周日一封：一读、一练、一件可以动手的事 |
| agent | agent | 能自己调用工具、把一件事做完的 AI |
| build 日志 | Build log | 公开记录我们怎样和 agent 一起做产品 |
| 内容线 | Track | 看清一站的三条线：里程碑、专业进阶、工程实践 |
| 叶与网 | Leaf and net | 首页主动效（方案 C）：叶子由几千个点组成，散开成网，再长回叶子 |
| 书脊 | Spine | 进入一站后，另一站收成的 56px 窄条，点它直接换站 |
| 步数预算 | Step budget | 每个场景从落地到完成允许的点按次数：核心两步，不常用三步 |

## 不再用的说法

| 不再用 | 改用 | 原因 |
|---|---|---|
| 搏击、搏击教练 | 力量训练、薄肌、Veli | 产品做的是健身薄肌，不是对抗性的搏击（11-03 产品负责人纠正） |
| worrycoach、Value Coach | Velicoach | 语音转写和早期设想，品牌已定为 Velicoach |
| 周信 | 每周邮件 | 自造词，读者看不懂 |
| xAI 的 prompt | （删除） | 语音转写错误，原意不成立 |
| 了解更多 | 写点了之后得到什么 | 两步原则：按钮直达结果 |
