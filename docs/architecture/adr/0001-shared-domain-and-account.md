# 0001 与 Veli 共用域名和账号，按路径分流

- 状态：已采纳（2026-11-03）
- 关联：Veli 仓库 ADR-0032（velicoach.com 按路径分给主站和 Veli）、主站 PRD 第 10 节「账号共用，数据分开」

## 背景

主站和 Veli 是两个项目，但用户应该只认一个站：在三站之间来回走，登录一次就够。

## 决定

- 采用 Veli 仓库 ADR-0032 的路由表：同一个域名，按路径分给两个 Vercel 项目。
- 账号用 Veli 的 Supabase Auth，不另建认证服务；主站只读名字和邮箱。
- 删除账号对两站同时生效（以 Veli PRD 的删除流程为准）。
- 本仓库里 Grok 沙箱自带的登录（`auth` 技能、`src/lib/auth`）只用于沙箱预览，不作为正式站的账号。

## 后果

- 登录状态和搜索权重集中在一个域名。
- 路由表要两个仓库一起维护；新增顶层路径前先查表。
- 主站要读取登录状态，但不能读健康数据；需要 Veli 数据的入口只做链接。
