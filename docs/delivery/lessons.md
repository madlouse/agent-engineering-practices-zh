## 工具与环境

- 2026-11-03 · 云端会话里 `gh issue`、`gh pr` 报 403 · 云端的 GitHub 代理不让 GraphQL 通过 · 一律用 `gh api` REST · 失效条件：代理放行 GraphQL 后 · 出处：Veli
- 2026-11-04 · 本仓库的云端会话装不了依赖（`npm run typecheck` 失败，没有 `node_modules`） · 和 Veli 同一个环境 · 类型检查、lint、构建以分支的 Vercel 预览部署为准（`pipeline.md` §7）；主站的 Vercel 项目还没建，见前置票 · 失效条件：有能装依赖的云端环境后
- 2026-11-04 · 用 `gh api` 建分支（`POST git/refs`）被代理拒绝（403），`git push origin <远端已有提交>:refs/heads/<新分支>` 也被拒 · 云端代理对这两种写法有限制 · 先建本地分支再 `git push origin <本地分支>`，可以 · 失效条件：代理放开以后
- 2026-11-03 · Agent 直接合并 PR、改权限设置会被系统拦下 · 这是对的 · 合并只走合并脚本，由权限设置单独放行；权限改动只出草稿，产品负责人放进去 · 失效条件：无 · 出处：Veli
- 2026-11-04 · `verify_canvas.py` 在主站画板上报了 29 条，其中 27 条是误报（token 没定义、触控过小）· 画板用 `/_blob/<id>` 引用共享样式表，本地读不到 · `verify_canvas.py` 加 `--blob <id>=<本地文件>`，同一块画板降到 2 条真问题；`selftest.py` 照样通过 · 失效条件：无
- 2026-11-04 · `verify_canvas.py` 在首页桌面画板上报「文字被挤成竖排」6 处，全是误报 · 渲染脚本不执行画板的 `renderVals()`，靠它算出的宽度都是空的；嵌套的 `<sc-for>` 也会把标签配错 · `render_dc.py` 在浏览器里执行一次 `renderVals()`（props 取默认值），`<sc-for>` 按配对的标签展开；首页四块画板降到 0 条，`selftest.py` 照样通过 · 失效条件：无
- 2026-11-04 · 画板加载不了外部脚本（three.js），上一版用静态圆点代替主动效，没人发现意思丢了 · 画板只能用自带的代码 · 画板里的动效用 WebGL2 直接写；评审截图要覆盖动效的几个状态 · 失效条件：画板支持外部脚本后

## 评审与流程

- 2026-11-04 · 冷评审：机制文档里写的命令少了必填参数（`verify_canvas.py --out`）、`check_page.py` 的宽度和主题和三种版式对不上，要的标杆卡仓库里没有，基线测试是红的 · 写规范的人没有把命令实际跑一遍，也没查材料在不在 · 写进规范、提示词、子 Agent 定义的每条命令都在本仓库实际跑一次；引用的文件、issue、标签逐个核对存在 · 失效条件：无

- 2026-11-11 · PR #102（订阅邮件的发送和记录规则）三轮评审都不过，按规则弃掉，重开成 PR #103 才过：每一轮为了回答评审指出的边界情况，往 ADR 里加一样机制（按封数分的措辞、过了窗口就停的新取值、窗口内重试、解锁再锁的退路、人工删行），新机制又带出新的边界情况 · 把评审意见当成「缺一条规则」来补，没有先问这个机制要不要；定义在 ADR 和票里各抄一份，抄的时候走样；在文档里预先设计实现时才知道要不要的退路 · 写进 `pipeline.md` §2.2：给机制写规格先定不变量和最简的规则，定义只写一处，按分得清的东西（结果类型）来写，边界情况留给实现和测试证明；评审指出边界问题时先问能不能删掉这个机制。重开时删掉了五样机制，对照表只剩六行 · 失效条件：无
- 2026-11-09 · 关口三 b 两轮冷审都找到「靠验收形成的环」：票的原生依赖没有环，验收却要等上线后才发生的事（工作流只在默认分支跑、切换域名、Veli 切换时的改动） · 写验收时没问「这一条在 `feature/v1` 上、上线前做得到吗」 · 每条验收标明在哪个环境做得到；做不到的挪进 `pipeline.md` §2.3「切换后」或 `launch-runbook.md`，不留在票里；要跑在默认分支上的东西（GitHub 工作流）先用 `chore/` PR 放进默认分支（上线前是 `feature/v1`，上线后改回 `site`） · 失效条件：无
- 2026-11-09 · 分流的路由表只列了页面路径，漏了 Veli 的 `/_next/*`，按表配 rewrites 页面会没有脚本和样式，状态码检查照样全过 · 只查了 HTML 的状态码，没查页面发出的请求 · 代理类的验收用 Playwright 记录页面发出的全部请求，4xx、5xx 为 0；路由表把静态资源和根目录文件逐个列出 · 失效条件：无
- 2026-11-04 · 并行的评审共用一个临时文件，评论贴错了 PR · 临时文件名冲突 · 子 Agent 的临时文件一律 `mktemp`，贴出后读回比对 · 失效条件：无 · 出处：Veli thin-muscle-coach#113
- 2026-11-03 · 冷评审的不阻塞建议合并后没人跟进 · 流程没规定建议的去向 · 每条建议定去向：本票改 / 开后续票 / 不采纳写理由 · 失效条件：无 · 出处：Veli thin-muscle-coach#8 复盘
