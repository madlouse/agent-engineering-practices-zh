## 工具与环境

- 2026-11-03 · 云端会话里 `gh issue`、`gh pr` 报 403 · 云端的 GitHub 代理不让 GraphQL 通过 · 一律用 `gh api` REST · 失效条件：代理放行 GraphQL 后 · 出处：Veli
- 2026-11-04 · 本仓库的云端会话装不了依赖（`npm run typecheck` 失败，没有 `node_modules`） · 和 Veli 同一个环境 · 类型检查、lint、构建以分支的 Vercel 预览部署为准（`pipeline.md` §7）；主站的 Vercel 项目还没建，见前置票 · 失效条件：有能装依赖的云端环境后
- 2026-11-03 · Agent 直接合并 PR、改权限设置会被系统拦下 · 这是对的 · 合并只走合并脚本，由权限设置单独放行；权限改动只出草稿，产品负责人放进去 · 失效条件：无 · 出处：Veli
- 2026-11-04 · 画板加载不了外部脚本（three.js），上一版用静态圆点代替主动效，没人发现意思丢了 · 画板只能用自带的代码 · 画板里的动效用 WebGL2 直接写；评审截图要覆盖动效的几个状态 · 失效条件：画板支持外部脚本后
