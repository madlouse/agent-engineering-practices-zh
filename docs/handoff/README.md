# 交接文档

一个阶段收尾、编排要换会话接手时，在这里放一份交接文档：现状、关口进度、开着的 PR 和分支、进行中的评审、遗留问题、等产品负责人决定的事、接手指南。文件名是收尾那天的日期。

- 最新一份：[2026-11-12.md](2026-11-12.md)（PRD 和设计的精简完善阶段收尾）。
- 交接文档记的是写的那一刻的状态，带核对时间；之后的状态以 GitHub 上的票、PR 和状态 issue #13 为准。旧的一份不再更新，新阶段收尾时另写一份，把上面这一行指过去。
- 规则不写在这里：关口、谁合并、什么算产品负责人的回复在 `docs/standards/pipeline.md`，安全约束在 `AGENTS.project.md`「不能越过的线」。
