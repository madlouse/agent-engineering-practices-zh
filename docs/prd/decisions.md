这是 Velicoach 主站 PRD 的决定记录。PRD（`docs/prd/velicoach.md`）只写「现在是什么」，历史决定和理由在这里；最新的在最上面。
文中的「第 N 节」指 PRD 的章节；标了「已由 … 的决定取代」（写明日期）的行是历史，不再生效。

## 2026-11-04 第二阶段「设计语言」的决定

**第二阶段「设计语言」的决定**（2026-11-04）

| 问题 | 决定 | 理由 |
| --- | --- | --- |
| 设计语言放在哪里 | 新建 [Velicoach 设计系统](https://claude.ai/artifact/6JqC3pUJ5GjDvXD2sEMZ5w)，作为主站的唯一来源；Veli 仍用 Veli 设计系统，两者共用叶子标识、纸色、苔绿和同一套玻璃参数 | 主站有三站三种底色，Veli 只管其中一站 |
| 首页主动效 | C「叶与网」：Veli 的叶子由几千个点组成，向右倾斜时散成一张网，向左时长回叶子；没有悬停的设备上跟着呼吸周期自动往返。产品负责人已确认 | 主角就是品牌签名；能延续成往下滚动的叙事（叶 → 网 → 搭起来的结构）。三个方向的对比见 [动效原型](https://claude.ai/artifact/PGihowSLLCHsh3xDx14Dtd) |
| 分站的背景 | A「墨入纸」降为几乎静止的纸墨质感；B「注意力」不采用 | 每屏只有一个主动效；粒子网格是常见的「AI 感」，缺少辨识度 |
| 渲染技术 | three.js WebGPURenderer 加 TSL，自动回退到 WebGL2，两者都不可用时显示静态画面 | 同一份着色器跑两种后端；原型已在两种后端上验证 |
| Veli 的玻璃 | Veli 设计系统加入同一套玻璃 token，代码同步见 Veli 仓库 PR thin-muscle-coach#96 | 全站按苹果设计语言统一，Veli 也加毛玻璃 |
| 语言切换的形式 | 导航最右端放分段控件「中文 \| EN」，选项用语言自己的名字，不用国旗；支持三种语言后再换成地球图标加菜单 | 只有两种语言时，分段控件当前状态一眼可见、一下切换；下拉菜单多一步，还把状态藏起来 |
| 手机、iPad、桌面的版式 | 按宽度分三档：< 744px 手机、744–1179px 平板、≥ 1180px 桌面；首屏倾斜只给有悬停和精确指针的设备，触屏 iPad 保持左右各半，内容全部可见 | 744px 是 iPad mini 竖屏的宽度，1180px 是 iPad Air 横屏的宽度；触屏上没有悬停，靠悬停才出现的内容会被藏住 |
| 折叠屏怎么支持 | 不另做版式：合上用手机版式，展开后按宽度落到手机或平板版式；折叠、展开不重新加载、不丢状态；浏览器报告了折痕位置时，首页的接缝对齐折痕，折痕上不放按钮和文字（渐进增强）【折痕对齐已由 2026-11-10 的决定取代：推到 v2】；半折立起来的桌面姿态，主站先不做 | iPhone Duo 外屏 382、内屏竖放 669、横放 951，Galaxy Z Fold7 内屏 984（CSS 像素），都落在已有的手机或平板版式里；Safari 的折痕接口还是要手动打开的实验功能，Chrome 138 起才默认支持，所以折痕只能做增强；首页本来就是左右两半，接缝正好可以对齐折痕 |
| 内容与版式的规范放在哪里 | 做成两个技能：velicoach-content 管所有内容的写作、审核和校准；velicoach-layout 管页面的排版、布局和多端适配 | 内容主要由 agent 生产，规范要能被 agent 按步骤执行；技术文章的排版沿用冯大辉的《中文技术文档写作风格指南》，页面规则以 Velicoach 设计系统为准 |
| 操作的步数 | 核心场景两步内，不常用的不超过三步，逐个场景见第 4 节「步数预算」；首屏放齐核心入口。登录原地完成、登录后换成「继续」，这两条 2026-11-09 移到 v2 | 产品负责人要求（2026-11-04）；只放一个按钮、点了再加载一个页面会多出一步 |
