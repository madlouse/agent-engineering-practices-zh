# 还没做完的产品

对照 [用户原话](../requirements/timeline.md)。已经在站上、而且原话没有再要求返工的，不写进这份范围。

读者是来看别人怎么和 agent 一起工作的人。他先看懂一篇，再决定要不要读原文。

## 要做

1. 站名不再叫「落地实践」。名字要像人和 agent 还要一起过很久，不像一个项目汇报。
2. 主页第一屏要有一张真正的图，而不是只有标题。图不解释文章，只让这个地方被记住。
3. 右上角切换中文和英文，全站都在，不只在某一篇里。没有英文正文的文章，切换后仍显示中文正文，并写明这篇还没有英文。
4. DeepSeek 那篇的架构图：找到稳定的官方文件才嵌入。找不到就保持现在的缺口说明，不另画。
5. 部署到 `velicoach.com/mind`（原计划的 `with.velicoach.com` 改为永久跳转过来，见主站 PRD [velicoach.md](velicoach.md) 的决定记录）。平台可以是 Vercel 或 Cloudflare。域名记录要等域名持有人改，代码里只准备站点能被这个名字访问的说明。
6. 旁白改成能落盘的开源声线，或站点自带、并且文件真的留下的声线。中文一条，美式英文另一条。在此之前，晓晓和 Andrew 继续能播。

## 先不做

- 不把 Claude、Shopify、Dan Koe 改成逐句全文。文末已经写明是整理。要改成全文，另开一份范围。
- 不把短片换成一段生成影像。现在的竖屏图和表继续用，除非单独的 issue 证明它让人记不住。
- 不把开篇那条残缺的 /loop 补写成全文。

## 怎样算做完

- 页眉、标题、分享卡上的站名一致，找不到「落地实践」当作现用站名。
- 主页桌面和手机都能看到那张图，图不是裂的。
- 任意文章页右上角都能切换语言。没有英文稿时，正文不变，说明可见。
- DeepSeek 要么嵌了官方原图，要么缺口说明还在。
- `docs/deploy.md` 写明上线到 `velicoach.com` 的分流和 `with.velicoach.com` 的跳转。真正改 DNS 不算本仓库能独立完成。
- 中英文旁白文件都在，而且来自开源声线或确认能落盘的站点声线。做不到就在该 issue 里写明试过什么、为什么仍用晓晓和 Andrew。
