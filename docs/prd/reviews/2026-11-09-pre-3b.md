## 结论

**就绪：否。** P0 5 条、P1 18 条、P2 8 条。

最要紧的一条是 **P0-2：v1 有没有登录，PRD 前后说法相反**。第 1、9、10、11 节说 v1 不需要登录、账号放到 v2；F01、F05、F24 这三个 P0 功能和整张步数表又都按「已登录」写了入口、账号菜单和订阅开关。它决定登录、账号菜单、「继续」入口、订阅开关、「继续读」这几组票做不做，所以要先定下来。

其余四条 P0：
- 订阅「提交即订阅」在三处下游文件里还写着二次确认；

- 主站没有「要确认的场景」清单，也没写哪些授权是法律要求单独同意的。

最近几轮的改动里，「一站、一键、一秒」「一秒分成回应和完成」「不用读就会用」在 PRD 正文里写到位了，和 U1、U7、U8、U9、C10 对得上。没落到位的是：
- 「意图步」没有进步数表（P1-9）；

### P0-5 主站没有「要确认的场景」清单，也没写哪些授权是法律要求单独同意的

- **位置**：

  - 同意的证据要存什么、表单旁边要告知什么，PRD 都没写。GDPR 第 7(1) 条要求能证明同意。
  - 不做二次确认在欧盟部分国家有法律风险，要不要接受这个风险，没有记录。
  - 主站面向中文读者，数据经美国的 Resend、Vercel、Supabase 处理。中国《个人信息保护法》第 39 条对向境外提供个人信息要求单独同意；适不适用要律师判断，PRD 没提。
  - 「不使用需要征得同意的 Cookie」（第 330 行）和下面两件事冲突，二者都没处理：
    - 内容约定允许原视频用官方可外链的地址（`AGENTS.project.md`「内容约定」），嵌入第三方播放器会写第三方 Cookie；

  - 动作；
  - 撤不回还是可撤销；
  - 默认授权还是意图步；
  - 法律要求的单独同意；
  - 存什么证据。

  至少包括：

  | 动作 | 推荐 |
  |---|---|
  | 订阅提交 | 默认授权（提交即同意）；表单旁边一行写清每周日发什么、可一键退订，并链到隐私政策；存邮箱、时间、页面语言、来源、表单文案的版本；欧盟和单独同意的问题请律师确认 |
  | 退订 | 一步生效，不挽留 |

  | 嵌入视频 | 点了才加载第三方播放器，或者用不写 Cookie 的嵌入方式 |
  | 字体 | 回退字体放在自己的服务器上，不从 Google 取 |
  | 统计 | 不写任何标识符（见 P1-12） |
  | 分享、投稿公开 | v2；撤不回，有意图步 |
  | 删除账号 | 在 Veli 里做；撤不回，有意图步 |
  | 健康数据、年龄与同意页 | 只在 Veli 里，按 Veli 的工作手册 |
