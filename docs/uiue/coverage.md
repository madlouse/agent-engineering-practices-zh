# 需求 → 画板覆盖表

主站 PRD v2.0（`docs/prd/velicoach.md` 第 4 节）的 27 个功能点（F04、F08 已删，F18 并入 F19），每个在 UI v1.0 画板里落在哪。核对日期：2026-11-11，按 PRD v2.0 重写；PRD 功能表原来的「画板 · 状态」一列迁到这里，所在的里程碑见 `docs/delivery/roadmap.md` §2.1。

- 画板：Claude Design 画布「Velicoach 主站 · UI v1.0」的 11 块画板：Main、Tablet、Mobile、Fold、Mind、Article、States、Body、Build、Project、Controls。状态写在各画板的 `data-props` 里，下面写成「画板 · 属性=值」。
- **画板还是 PRD v1.2 时画的，没有按 v2.0 改。** v2.0 新增或改了的界面，下面写「没画：画板下一版补，补完过关口三 a」；v2.0 删掉或推后的界面还留在画板上，列在「画板上多出来的」。**画板下一版和关口三 a 补评（关口票 #94，它等设计系统下一版 #93），是受影响的界面票开工的前提**（`docs/delivery/roadmap.md` §2）。
- 检查命令（`design-bar` 技能）：

```
python3 .grok/skills/design-bar/scripts/coverage.py --prd docs/prd/velicoach.md --canvas <画板目录> --map docs/uiue/coverage.md
```

- 判法：「已画」行写画板和状态；只画了一部分的，备注以「部分：」开头，写清缺什么。「无界面」行第二列写 `—`。「没画」的功能不进映射表，单列在后面，检查命令会把它们报成「没有着落」，这是有意的。
- 统计：已画 6，部分画 11，无界面 6，没画 4（共 27 个）。

## 步数预算核对

按 PRD v2.0「步数预算」表逐个在画板上走。v1 只数未登录：主站不读登录状态；在 Veli 登录过的人点「开始训练」1 步，由 Veli 带到今天的训练。画板还是旧版，「没画」的行等画板下一版补完再核。一步是一次有意的点按或提交；悬停、滚动、输入不算；系统账号选择算一步。

- 手机和平板只画了首页首屏：Mind、Article、Body、Build 的手机版式，以及首页首屏以下（宣言、最新文章、页脚）的手机版式没有画。P6「手机和 iPad 用户」点进一站以后看到什么，目前只能按 `velicoach-layout` 技能的三种版式规则推。P2：规则已有，实现时按规则做，再用走查补截图。
