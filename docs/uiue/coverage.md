# 需求 → 画板覆盖表

主站 PRD v2.0 第 505 版（`docs/prd/velicoach.md` 第 4 节）的 27 个功能点（F04、F08 已删，F18 并入 F19），每个在 UI v1.1 画板里落在哪。核对日期：2026-11-12，按 PRD 第 505 版和 18 块画板重写；所在的里程碑见 `docs/delivery/roadmap.md` §2.1。

- 画板：Claude Design 画布「Velicoach 主站 · UI v1.1」（地址见 `docs/README.md`）的 18 块；画板文件在 `docs/uiue/prototypes/v1.1/boards/`。
  - 页面画板 10 块：Main（首页）、Mind（看清首页）、Learn（学习路径）、Article（文章页，单条开发日志复用）、Build（动手）、Project（项目页）、About（关于）、States（页面状态）、Body（站稳，参考：由 Veli 仓库实现）、Controls（控件状态和组件样张）。
  - 设备画板 8 块：Tablet、Mobile、Fold（首页的平板、手机、折叠屏内屏）、MindMobile、LearnMobile、ArticleMobile、BuildMobile、AboutMobile。每个页面是同一份标记，靠媒体查询在三种版式下成立；设备画板由页面画板生成，只改标题和预览尺寸，页面画板改了以后重新生成。Project、States、Body 没有单独的设备画板，手机和平板宽度由验证器在同一块画板上查（390、320、820 宽）。
  - 状态写在各画板的属性（`data-props`）里，下面写成「画板 · 属性=值」。除 Controls、Body 以外，每块都有 `theme=自动/浅色/深色`、`lang=中文/English`、`subscribeGate=开/关`、`nav=首屏/吸顶`；Body 没有 `subscribeGate`，Controls 只有 `theme`。
- 核对方法：逐块读画板的属性、设计简报（`brief.md`）、两轮独立评审和修改对照（`reviews/2026-11-12-audit/`）；这次重写没有逐张重新看图。第三轮小修以后只改了学习路径、提示条和登录按钮顺序相关的行。
- 检查命令（`design-bar` 技能；`<画板目录>` 用 `docs/uiue/prototypes/v1.1/boards`）：

```
python3 .grok/skills/design-bar/scripts/coverage.py --prd docs/prd/velicoach.md --canvas <画板目录> --map docs/uiue/coverage.md
```

- 判法：「已画」行写画板和状态；只画了一部分的，备注以「部分：」开头，写清缺什么。「无界面」行第二列写 `—`。「没画」的功能不进映射表，单列在后面，检查命令会把它们报成「没有着落」，这是有意的。
- 统计：已画 17，部分画 2，无界面 6，没画 2（共 27 个）。v1 要做的 23 个里，已画 17、部分画 2、无界面 4（F27、F28、F29、F30）；没画的 2 个和无界面里的 F17、F26 是 P2。检查命令 2026-11-12 的结果（画板目录用制作时导出的 18 块）：它把并入 F19 的 F18 也数成一个，范围 28 个，画板里提到 3 个，覆盖表映射 20 个，写明无界面 6 个，报「没有着落」的是 F12、F20 两个 P2。
- v2：主站 v1 不读登录状态（`docs/requirements/timeline.md` 第 80 条），导航里的「登录」和头像、账号菜单、首屏的「继续」类入口、登录后用户自己关订阅的控件都在 v2。搜索（F26）、里程碑的类型筛选、首页「今天的训练」入口、折叠屏的折痕对齐在 PRD v2.0 推到 v2（PRD 第 9 节「版本范围」）。画板上没有这些控件。
