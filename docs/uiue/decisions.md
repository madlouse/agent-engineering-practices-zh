## 2026-11-13 · 研究卡大数字收紧（主频道定）

- **决定**：大数字只用于证据可信度是「高」或「中」、并且外行读得懂的数；可信度「低」「很低」的，或者研究只给出效应量的，不放大字，数写进方法一行，卡片排成行。每张研究卡都标可信度。
- **理由**：三种可信度用同样的音量，读者会把低可信度的数读成同样可靠；效应量是统计量，当大字就是 `design-bar` 的反面模式「行话大字」（PR #144 的独立评审）。
- **取代**：本文件「研究卡和文案」一表里「情绪卡的大数用效应量」一条，以及「数字卡的读法」一条里大数字不分可信度的部分。
- **检查**：`npm run check:research-metric` 查画板这类写死在标记里的 `data-credibility`；站点代码按数据渲染的，由站点票 #52 的数据检查查同一条。写进 `docs/standards/pipeline.md` §7，合并脚本合并前重跑。
- **改了哪里**：`docs/standards/quality-terms.md` T8（第 8 版）、本文件、设计系统「数字卡（研究卡）」、`velicoach-content`「研究卡」、`velicoach-layout`「卡片」、`pipeline.md` §7、`scripts/merge-ticket-pr.sh`。
