# 站名、主页、语言

先于改代码。只定这三件事。

## 站名

中文用「同席」。英文用 With。

同席是人和 agent 坐在同一张桌子上，把做法留下来。不用「落地」「实践」「赋能」。

页眉左侧只放「同席」。窄屏不放副标题。宽屏副标题是「人和 agent」。

浏览器标题和分享卡标题都是「同席」。描述一句：人和 agent 一起工作、生活，把做法留下来。

## 主页

第一屏仍是现在的纸色和衬线，不换一套视觉。

标题换成：人和 agent，坐在同一张桌子上。

标题右侧或下方放一张横图，大约 3:2。内容是一张木桌，一边是人的笔记，一边是摊开的终端，没有脸部特写，没有图标堆。纸色环境光，不另加一种主色。

图裂开时，标题单独成立，不留灰块。

## 语言

页眉右侧，导航之后：中文、English。两个字按钮，当前项是墨色底。点按区域不小于 44 像素。

选择记在这一次浏览里。刷新可以回到中文。先不要求跨设备记住。

英文时：导航、页眉副标题、主页标题和说明用英文。文章有英文稿才换正文。没有英文稿，正文保持中文，文首一行：这篇还没有英文。

短片上的「晓晓 / Andrew」留下。它换的是声音，不是全站语言。全站切到 English 时，短片默认 Andrew。切回中文时，短片默认晓晓。
