# 同席在 Velicoach 里的位置

站点名是 **Velicoach**。「同席」（英文 With）是「看清」一站的刊名：人和 agent 坐在同一张桌子上，把做法留下来。看清一站的地址是 `velicoach.com/mind`，文章在 `velicoach.com/mind/<slug>`。

视觉、版式、语言切换和主题都以 Velicoach 设计系统为准（[design-system.md](design-system.md)）。下面只记同席自己的约定。

## 留下的

- 刊名「同席」，英文 With。不用「落地」「实践」「赋能」。
- 一句描述：人和 agent 一起工作、生活，把做法留下来。用在看清一站的首屏和分享卡上。
- 讲解短片的旁白：中文晓晓，英文 Andrew。它换的是声音，不是全站语言；全站是英文时默认 Andrew，是中文时默认晓晓。

## 改掉的

| 原来 | 现在 | 原因 |
|---|---|---|
| 页眉左侧放「同席」，浏览器标题是「同席」 | 页眉是 Velicoach 的胶囊导航；看清一站的页面标题写「看清 · 同席」 | 同席并入主站，成为一站的刊名 |
| 主页第一屏是纸色加衬线，配一张木桌的横图 | 看清一站的首屏是墨色、衬线标题；阅读区跟随浅色、深色主题 | 设计系统「三站，三种底色」「浅色与深色」 |
| 语言按钮「中文、English」，只记在这一次浏览里 | 导航最右端的「中文 \| EN」，选择会被记住，英文在 `/en/` 下 | 设计系统「导航与语言切换」 |
| 没有英文稿的文章，英文页面显示中文正文 | 中英两版同时发布，英文页面不出现中文正文 | 主站 PRD 关键路径 P5 |

现有代码还是同席的旧首页；做主站页面时按本表一起改。
