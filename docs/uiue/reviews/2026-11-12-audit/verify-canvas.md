# 画板验证报告

**结论：needs_work**（2 个问题，10 块画板，主题：light,dark,pseudo）

只报能判对错的问题，每条给出位置和量出的数：会让用户看错、点不到、看不清的，以及带阈值的版面量度（首屏空白带、相邻色面、跨画板左边缘、字号种类）。构图和审美交给评审。

阈值：相邻色面 ≥ 1.8:1（通用的下限，项目定了更高的门槛用 --face-contrast 调高）；首屏空白带 ≤ 视口的 30%；左边缘容差 2px；字号 ≤ 8 种；点按区域 44 / 24px。

按说明文档跳过触控、首屏、空白带、色面、字号种类、左边缘的画板：Controls.dc.html（带 expand，根节点写了 data-board="doc"）。
